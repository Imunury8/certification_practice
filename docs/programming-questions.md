# 프로그래밍 언어 활용 문제

[Q-Net 정보처리기사 출제경향](https://www.q-net.or.kr/crf005.do?gId=&gSite=Q&id=crf00503s02&jmCd=1320&jmInfoDivCcd=B0)의 프로그래밍 언어 활용 범위를 연습하는 자체 제작 코드 출력 문제입니다.

`lib/programmingQuestions.ts`에 C, Java, Python 각각 30문항을 수록했습니다. 각 언어는 기본·중간·실전 난이도별 10문항이며, 숫자만 바꾸는 변형 대신 서로 다른 문법과 실행 흐름을 다룹니다.

| 언어 | 주요 연습 내용 | 실행 기준 |
| --- | --- | --- |
| C | 포인터, 이중 포인터, 구조체, 배열, 문자열, 함수 포인터, static, 재귀, 정렬 | C99 |
| Java | 상속, 필드 숨김, 오버로딩, 동적 바인딩, 생성자·초기화, 배열 복사, 컬렉션, 예외 | Java 8 이상 |
| Python | 슬라이싱, 참조·얕은 복사, 컴프리헨션, 딕셔너리·집합, 기본 인수, 상속, 클로저, 제너레이터 | Python 3 |

문제 화면에서 언어를 선택할 수 있습니다. 혼합 출제는 세 언어를 고르게 선택하며, 기존 출제 기록에 따라 보지 않은 문항을 먼저 출제합니다. 출력 채점은 대소문자와 값의 구분을 유지하고, 줄바꿈·연속 공백·숫자 리스트의 공백 차이는 허용합니다.

## 검증

`npm test`는 문항 구성, 언어별 출제, 중복 방지, 출력 채점을 검사합니다. 실제 코드 실행 결과는 아래 명령으로 별도 검증합니다.

```sh
npm run verify:programming
```

기본 명령은 `python`, `javac`, `java`, `gcc`입니다. 경로가 다른 경우 `QUIZ_PYTHON_BIN`, `QUIZ_JAVAC_BIN`, `QUIZ_JAVA_BIN`, `QUIZ_C_COMPILER` 환경 변수로 실행 파일을 지정할 수 있습니다. C 컴파일러는 GCC, Clang, TinyCC처럼 `-std=c99 -Wall 입력.c -o 출력` 옵션을 지원해야 합니다.

검증기는 저장된 모든 소스를 임시 디렉터리에 쓰고 직접 실행하여 출력 문자열을 정답과 비교합니다. 실행 환경이 없거나 컴파일·출력 비교가 실패하면 실패로 종료하며, 검증 후 임시 디렉터리를 정리합니다.
